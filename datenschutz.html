Keine Datenerfassung, keine Cookies, keine Analysetools

Diese Website ist als rein statische Informationsseite konzipiert. Wir erfassen keinerlei persönliche Daten von Ihnen, wenn Sie diese Website besuchen. Es gibt keine Kontaktformulare, keine Kommentarfunktionen und keine Benutzerkonten.

Wir setzen keine Cookies, keine Tracking-Skripte und nutzen keine Webanalysedienste (wie z.B. Google Analytics). Die interaktiven Funktionen (wie der Solar-Sparrechner) laufen vollständig lokal in Ihrem Webbrowser; es werden keine Eingabedaten an uns oder Dritte übertragen.

Hosting über GitHub Pages

Wir hosten unsere Website bei GitHub Pages. Anbieter ist die GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA.
