# 1A NRG (1anrg.de)

Category: construction-energy

## Concept
A clear, practical German guide to home energy: comparing heat pumps, rooftop solar, balcony solar (Balkonkraftwerk), home batteries and insulation. Centerpiece: an interactive savings estimator (roof size, consumption, region) that runs fully in the browser with clearly stated assumptions.

## Look
Bright, optimistic: deep green and warm yellow on off-white, bold geometric sans headings, simple line icons.

## Architecture & Structure
This is a purely static website built with plain HTML, CSS, and vanilla JavaScript. It requires no build step and is served directly via GitHub Pages.

- `index.html`: Main landing page containing guides and the interactive savings estimator.
- `impressum.html`: Standard imprint page.
- `datenschutz.html`: Privacy policy stating no data collection.
- `404.html`: Custom error page.
- `style.css`: All styling, including a responsive layout and a dark mode fallback (`prefers-color-scheme: dark`).
- `script.js`: Interactive logic for the savings estimator (runs entirely in the browser).
- `favicon.svg`: Vector icon used for the favicon.
- `sitemap.xml` & `robots.txt`: Basic SEO files.
